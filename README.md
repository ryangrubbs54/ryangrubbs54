### [AI Customer Support Email Agent](https://github.com/Ryangrubbs54/AI-Customer-Support-Email-Agent)

A **portfolio demonstration** of an AI-assisted customer support workflow built with **n8n, OpenAI, Gmail, Google Sheets, JavaScript, and Docker**.

The system:
- Monitors incoming test emails and categorizes customer inquiries.
- Extracts order numbers and checks fictional order records.
- Compares sender addresses to order records before preparing order-specific replies.
- Creates **Gmail drafts for human review**, rather than automatically sending replies.
- Tracks message processing, draft outcomes, duplicate detection, and exceptions.
- Includes separate error logging and monitoring for stalled processing.

### [AI Portfolio Assistant — Full-Stack RAG Chatbot](https://ryangrubbs.netlify.app)

A live, full-stack **retrieval-augmented generation (RAG) assistant**, built with **Next.js, React, TypeScript, OpenAI, Supabase PostgreSQL, and pgvector** and integrated into my professional portfolio website.

The system:
- Provides an interactive chat experience for questions about professional experience, skills, projects and services.
- Embeds user questions with OpenAI and searches a curated public portfolio knowledge base using pgvector semantic similarity.
- Uses retrieved document excerpts to generate grounded responses with supporting source links.
- Keeps API credentials on the server and applies database-backed request limits.
- Runs on Netlify via a Next.js backend API route.

**Architecture:** Visitor → Next.js API → OpenAI embedding → Supabase pgvector retrieval → OpenAI response → source-linked chat answer.

**[Try the live assistant →](https://ryangrubbs.netlify.app)** (select the AI Assistant button). The website source repository is private; the live demo and this architecture overview are public.
